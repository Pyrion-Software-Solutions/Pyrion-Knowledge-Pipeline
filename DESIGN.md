# Document preparation workbench

Mode: Operate. The approved brief calls for a simple, functional local dashboard.

Use a quiet paper-white workspace, ink text, a dark teal navigation rail and warm copper for pending-review emphasis. System UI fonts provide locally available Persian and English glyphs without network fonts. Documents use generous line height, preserved whitespace and automatic text direction. Review content is arranged in a readable report with source and proposal together, not scattered across metric cards. Sidebar navigation, a clear current state, and a persistent review action area carry the workflow. Forms have visible labels and keyboard focus; status is conveyed with text as well as color. Mobile stacks the navigation and report columns.
